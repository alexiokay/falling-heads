# 🌍 MineHeads - Complete Biome Guide

## Overview
- **7 Total Biomes** with unique terrain, enemies, and resources
- Biomes change **vertically every ~450 blocks** (7 chunks)
- **Dynamic procedural generation** - random biome order each playthrough

---

## 1. 🌾 Plains Biome

### ✅ Current Features
- **Terrain Block**: Grass (green)
- **Decorative Blocks**: Pumpkin, Melon (5% spawn chance)
- **Ore Blocks**: Coal, Iron, Gold, Diamond, Emerald, Redstone
- **Enemies**: Skeletons (50% spawn rate)
- **Buffs**: None (safe biome)
- **Cave Generation**: Moderate frequency, small caves

### ❌ Missing Features
- **Background Texture**: Currently solid color
- **Unique Mechanics**: No special gameplay features
- **Ambient Effects**: No weather or particles

### 💡 Proposed Improvements
**Background Texture Options**:
- Light blue sky with white clouds (parallax scrolling)
- Grass field pattern with flowers
- Sun/moon based on Y position

**Suggested Blocks to Add**:
- Flowers (cosmetic)
- Tall Grass (cosmetic)
- Wheat/Crops (farmable)

**Gameplay Feature Ideas**:
- Higher villager spawn rate (farming community)
- Regeneration buff from melons/pumpkins

## 4. ⛰️ Mountains Biome

### ✅ Current Features
- **Terrain Block**: Stone (gray)
- **Decorative Blocks**: Snow (5% spawn chance)
- **Ore Blocks**: Coal, Iron, Gold, Diamond, Emerald, Redstone (more common)
- **Enemies**: Skeletons (50% spawn rate)
- **Buffs**: **Freezing** from Snow blocks (20% chance, 3s duration)
- **Cave Generation**: Moderate frequency, small caves

### ❌ Missing Features
- **Background Texture**: Currently solid color
- **Mountain Peaks**: No visual height indication
- **Snow Coverage**: Not enough snow

### 💡 Proposed Improvements
**Background Texture Options**:
- Light gray/white misty clouds
- Distant mountain peaks silhouette
- Snowfall particle effect
- Aurora borealis (rare, high altitude)

**Suggested Blocks to Add**:
- Ice (slippery - affects physics)
- Packed Ice (doesn't melt)
- Blue Ice (very slippery)
- Frozen Stone (stone with ice coating)

**Gameplay Feature Ideas**:
- Slippery physics on ice/snow
- Freezing slows movement (already implemented)
- Avalanche mechanic (falling snow/ice blocks)
- Rare emeralds more common here

## 5. 🕳️ Underground Biome

### ✅ Current Features
- **Terrain Block**: Stone (dark gray)
- **Decorative Blocks**: Mushroom, Vines (5% spawn chance)
- **Ore Blocks**: Coal, Iron, Gold, Diamond, Emerald, Redstone (higher density)
- **Enemies**: Skeletons (70% spawn rate - DANGEROUS!)
- **Buffs**: **Poisoned** from Mushrooms (20% chance, 4s duration, 1 damage/sec)
- **Cave Generation**: VERY FREQUENT, larger caves

### ❌ Missing Features
- **Background Texture**: Currently solid color (should be DARK)
- **Lighting System**: No darkness/light sources
- **Stalactites/Stalagmites**: No cave decorations

### 💡 Proposed Improvements
**Background Texture Options**:
- Very dark gray/black (almost pitch black)
- Subtle rock texture
- Glowing mushroom spots (bioluminescence)
- Cave crystal reflections

**Suggested Blocks to Add**:
- Glowstone (light source)
- Lanterns (light source)
- Stalactite (hanging from ceiling)
- Stalagmite (growing from floor)
- Moss Stone (overgrown stone)
- Crystal Ore (glowing decoration)

**Gameplay Feature Ideas**:
- **Darkness mechanic** - can't see far without light
- Glowstone provides light radius
- Mushrooms spread poison gas (area effect)
- More enemy spawns in darkness
- Rare ores more common (diamond, emerald)

## 6. 🔥 Nether Biome

### ✅ Current Features
- **Terrain Block**: Netherrack (dark red)
- **Decorative Blocks**: Soul Sand, Glowstone (5% spawn chance)
- **Ore Blocks**: **Ancient Debris, Netherite, Obsidian, Gold** (unique!)
- **Enemies**: Skeletons (80% spawn rate - VERY DANGEROUS!)
- **Buffs**: **Slowness** from Soul Sand (20% chance, 3s duration)
- **Cave Generation**: Frequent small caves

### ❌ Missing Features
- **Background Texture**: Currently solid color (should be RED/ORANGE)
- **Lava Generation**: No lava blocks/rivers
- **Fire Effects**: No burning particles
- **Unique Enemies**: Only skeletons (needs Pigmen)

### 💡 Proposed Improvements
**Background Texture Options**:
- **Dark red/orange glowing background** (lava glow)
- Lava river silhouettes in distance
- Ember/ash particle effects
- Pulsing red glow (animated)
- Nether fortress silhouettes

**Suggested Blocks to Add**:
- **Lava** (damage on touch, glowing)
- **Magma Block** (slow burn damage)
- **Blackstone** (dark nether stone)
- **Crying Obsidian** (glowing purple)
- **Nether Wart** (alchemical ingredient)
- **Basalt** (pillar formations)

**Gameplay Feature Ideas**:
- **Lava pools** - instant death/heavy damage
- **Burning debuff** - catch fire from lava/magma
- **Pigman enemies** (already coded but needs more spawns)
- **Nether fortresses** - rare structure generation
- Ancient Debris only spawns here (for Netherite crafting)
- Soul Sand creates "soul fire" (blue fire)

**Critical Missing**: **LAVA BACKGROUND GLOW** - should be red/orange ambient!

## 7. 🌌 End Biome

### ✅ Current Features
- **Terrain Block**: End Stone (pale yellow)
- **Decorative Blocks**: Chorus Fruit, Purpur (5% spawn chance)
- **Ore Blocks**: Obsidian, Diamond, Emerald (unique set)
- **Enemies**: None (PEACEFUL biome)
- **Buffs**: **Speed** from Chorus Fruit (20% chance, 5s duration)
- **Cave Generation**: Less frequent, tiny caves

### ❌ Missing Features
- **Background Texture**: Currently solid color (should be VOID/SPACE)
- **Floating Islands**: Terrain is continuous
- **End Cities**: No structures
- **Unique Atmosphere**: Doesn't feel alien enough

### 💡 Proposed Improvements
**Background Texture Options**:
- **Dark purple/black void with stars**
- Distant floating islands silhouette
- Purple particle effects (enderman particles)
- Slow-moving nebula clouds
- Ender dragon flying in distance (cosmetic)

**Suggested Blocks to Add**:
- **Void Block** (instant death - bottomless pit)
- **End Rod** (light source, white glow)
- **Shulker Block** (decorative)
- **Ender Pearl Block** (teleportation mechanic)
- **Chorus Plant** (tall growing structure)
- **Bedrock** (indestructible - marks world borders)

**Gameplay Feature Ideas**:
- **Floating island generation** - gaps/voids between platforms
- **Low gravity** - physics modifier (higher jumps)
- **Chorus fruit teleportation** - random short teleport on eat
- **Enderman enemies** (teleporting, peaceful until attacked)
- **Ender dragon boss** (flies in background, shootable)
- **Levitation buff** - rare spawn

## 📝 Notes

**Current Background System**:
- Uses solid color per biome (from block textures)
- No parallax scrolling
- No animated backgrounds
- Located in: `src/systems/background_system.rs`

**Easy Wins**:
1. Change background colors to match biome mood
2. Add simple gradient (top/bottom different colors)
3. Add texture tiling for depth

**Future Enhancements**:
- Parallax layers (far, mid, near)
- Animated backgrounds (moving clouds, lava flow)
- Weather effects (rain in Forest, sandstorms in Desert)
